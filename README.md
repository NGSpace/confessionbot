Confession bot is a discord bot that allows for completely anonymous confessions while also allowing moderators to ban abusers.

# How to operate

1. Make a discord bot (go [here](https://discord.com/developers/applications) and do whatever the fuck they ask you to do and get your discord bot's token)
2. Download the latest jar and put it in a folder
3. Run the jar
4. Edit token.txt and paste your bot token there
5. Run the jar again.
